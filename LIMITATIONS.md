# Limitations

ClosureProbe v0.1:

- does not prove that a data source is truthful, current, exhaustive in reality,
  or authorized to speak for the world;
- does not infer semantic equivalence between different natural-language or API
  queries;
- does not treat a successful HTTP or MCP request as proof of query completeness;
- does not automatically observe proprietary model prompts or hidden client
  transformations;
- does not certify legal compliance, medical correctness, sanctions clearance,
  vulnerability absence, eligibility, or any other consequential decision;
- does not replace cryptographic query-verification systems;
- does not use an LLM judge in its normative conformance result;
- cannot assign completeness to an unprofiled API; and
- reports producer-declared, profile-validated closure, not metaphysical
  nonexistence.

Black-box model-visible probes are empirical observations. They MUST be labeled
with target version, model, repetition count, and visibility limitations.
