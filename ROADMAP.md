# Roadmap

ClosureProbe rc3 ends the planned internal semantic-hardening cycle. The next
milestone is not another provider, schema, or pre-announced P6. It is external
empirical evidence.

## Immediate experiment

Run the controlled differential matrix through real MCP clients and preserve:

- exact client and model version;
- `dual`, `structured-only`, and `text-only` carrier results;
- complete, partial, continued, segment-only, denied, failed, and scope-
  mismatch scenarios;
- wire, client-retained, model-visible, and claim stages where observable; and
- raw capture artifacts plus normalized anchored traces.

A fully preserved result is valuable. A localized loss is more actionable. A
hidden boundary remains explicitly unmeasured.

## Evidence-selected successors

| Observed bottleneck | Candidate next primitive |
| --- | --- |
| guard loss clusters in adapters or clients | preservation adapter or runtime decision gate |
| capture and normalization dominate effort | target-specific capture kits |
| producer semantics dominate failures | reviewed profile registry and authoring verifier |
| accountable review is requested | signed evidence packets, policy hooks, and recourse-aware records |
| no external demand appears | do not manufacture a sequel |

Any integration with earlier RISU projects must add enforceable semantics at a
real decision boundary, not concatenate schemas or project names.
